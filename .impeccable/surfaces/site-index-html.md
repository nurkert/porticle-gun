# Surface: PorticleGun website (site/index.html)

Mode: Persuade. Audience: server admins and players equally. Action: download the latest release directly; understand
what the plugin is, how it is used and what it brings. Proof: the real GIFs and renders in images/. Constraints: static
HTML/CSS/JS, GitHub Pages, English copy, rift never contains black, no invented numbers or testimonials.

Seed: c649e421 (direction scope, persuade), user chose the pick card: Minecraft inventory GUI world.

## Direction contract

THESIS: The page is the game's own inventory screen. Refuses the generic plugin landing page of cards on a neutral
ground.

OWN-WORLD: Blurred, dimmed world behind every screen like the modern pause menu. Light grey bevelled GUI windows with
black pixel outlines, recessed slots, stone buttons with white hover outline, purple-bordered tooltips, a pixel display
face with drop shadow, dark grey window labels. Orange, blue and rift green only as item light.

STORY: Hero shows both guns in preview slots and the download. Then portals, gravity, rifts, fuel, atlas, crafting,
controls, download chest, docs, each a different GUI window.

FIRST VIEWPORT: Big GUI window with the turning guns in preview boxes that lean toward the cursor, tagline, download
button with the live version, and the hotbar fixed at the bottom with the XP bar.

SIGNATURE: The hotbar is the navigation: scrolling moves the selected slot, the held item name fades in above it, the
XP bar fills with scroll progress, keys 1 to 9 jump. Item tooltips everywhere.

RISK: Pixel type can hurt reading; body copy stays in a clean sans, the pixel face only for display, labels and
tooltips.
